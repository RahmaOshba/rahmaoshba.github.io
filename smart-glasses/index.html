To See: smart glasses for blind people

A wearable camera on a pair of glasses, controlled by a small joystick. It reads text, describes objects, recognises faces and lets the user chat by voice, using machine learning and web technologies.

01

My role

Machine learning

I worked on the machine learning part: the models that turn what the camera sees into words the user can hear.

  • Text reading (OCR) with PaddleOCR
  • Object detection with YOLOv8
  • Face recognition with TensorFlow, Keras and OpenCV
  • Text-to-speech so every result is read aloud
02

What it does

Reads text

Point at a sign, a label or a page and the glasses read it aloud.

Finds objects

Names the objects in front of the user in real time.

Knows faces

Recognises saved family and friends and says who is there.

Voice chat

Sends photos and voice notes, and reads new messages aloud.

03

How it works

A Raspberry Pi 4 with an 8 MP camera captures the image. A Flask API runs the machine learning models, a .NET Core server stores the data in the cloud, and a React website and a Flutter app let sighted family members talk to the user.
